# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life, even though I often use cloud services without realizing it. Three cloud-based services that I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of **Software as a Service (SaaS)** because it allows users to store, access, and manage files through a web browser without installing complex software or managing servers. It operates mainly under a **Public Cloud** deployment model since it is available to anyone with a Google account through shared cloud infrastructure.

Facebook Messenger is also classified as **SaaS** because it provides messaging and communication services over the internet. It uses a **Public Cloud** deployment model because millions of users access the same cloud-based platform while their data remains separated and secured.

Canva is another **SaaS** application because it provides online graphic design tools through a web browser. Like Google Drive and Messenger, Canva is commonly considered part of the **Public Cloud** since it is available to the general public and hosted on cloud infrastructure managed by the provider.

Version control is a critical component of cloud infrastructure management. Cloud environments often involve configuration files, scripts, and application code that multiple people may modify simultaneously. Without version control, it would be difficult to track changes, identify errors, or restore previous versions when problems occur.

Git and GitHub provide an effective solution by recording every change made to files and projects. GitHub allows team members to collaborate through branches, pull requests, and commit histories. These features help developers review modifications before deployment and reduce the risk of accidental errors. In cloud projects, version control also supports accountability because every change is associated with a specific contributor. By using GitHub, teams can work more efficiently, maintain organized project histories, and ensure that cloud resources are managed safely and consistently.

Overall, cloud computing and version control work together to support modern technology. Understanding these concepts helps me become more prepared for real-world IT and software development environments.
